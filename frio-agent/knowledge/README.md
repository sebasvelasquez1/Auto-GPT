# Knowledge — referencias de mercado para el agente Frío

Esta carpeta guarda investigación externa (mercado, competidores, herramientas,
métodos) que sirve de referencia al construir y afinar Frío. No es código — es
la memoria de "qué existe afuera y qué aprendimos de eso".

## Regla del research (obligatoria, sin excepciones)

**No inventar. No presumir. No redondear hacia lo que suena bien.**

1. Toda afirmación sobre una herramienta/competidor/dato de mercado debe venir de
   una fuente real y citada (URL). Si no se verificó, se marca explícitamente
   como **NO VERIFICADO**.
2. Si el usuario pega un texto con cifras/afirmaciones, se contrastan con una
   búsqueda independiente antes de repetirlas. Si no coinciden, se documenta la
   **discrepancia** tal cual — no se elige la que "suena mejor" ni se promedia.
2b. Nunca se presenta una cifra de marketing de la propia empresa como un hecho
   verificado por un tercero — se etiqueta como "auto-reportado por el vendedor".
3. Distinguir siempre: ¿esto es una herramienta que un HUMANO opera y decide, o
   un AGENTE que decide y ejecuta solo? Esa distinción es el corazón de nuestra
   tesis de diferenciación — no se puede asumir, hay que confirmarla por producto.
4. Cuando la certeza es baja o el research no fue exhaustivo, se dice
   explícitamente "esto no fue una búsqueda exhaustiva" — nunca se presenta una
   búsqueda parcial como si fuera el mapa completo del mercado.

Ver `investigacion/` para los documentos concretos, cada uno con sus fuentes.
